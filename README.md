# 🏦 Banking System - Web Version

A web-based version of the Banking System Mini Project built with **Python and Streamlit**.

## Features

- Create a bank account
- Login with account number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

This project can be deployed using Streamlit Community Cloud from the GitHub repository.

> **Demo limitation:** account data is stored in Streamlit session memory. It is intended for demonstration/internship project use and is reset when the app session restarts. It is not a real banking system and should not be used for real financial data.
